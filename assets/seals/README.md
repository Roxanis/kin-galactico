# Biblioteca de Sellos

Esta carpeta contiene una primera serie propia de imagenes SVG para los 20 sellos solares.

## Como se usan

- La calculadora busca primero una imagen especifica por `kin`.
- Si no existe, usa la imagen del sello correspondiente desde esta carpeta.
- Si por alguna razon tampoco encuentra ese archivo, cae al SVG generado por `app.js`.
